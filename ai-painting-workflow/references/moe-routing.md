# moe-routing — 绘画域 MoE 路由矩阵全表

> **何时加载**: 选模型/调采样参数/多模型协作/批量任务分流时。
> **总则**: 每个子任务先声明 tier 再路由；T0 挂了自动降级 T1 备份；便宜模型黄金集评分降幅 >5% 立即回退。

## 2. 厂商工具协议差异（关键坑）

| 厂商 | 工具协议 | 强制 JSON schema？ | 备注 |
|---|---|---|---|
| GLM-4.6 | **XML 工具模板** | ❌ 别强套 | 用 XML 模板，JSON schema 会崩 |
| DeepSeek / Qwen / Kimi / Doubao | JSON schema function calling | ✅ | 标准 JSON 调用 |
| MiniMax M2 | JSON schema | ✅ | 复杂多跳友好 |

**适配器原则**: 差异包在一层适配器里——引擎侧调用统一入口，模型侧按厂商协议转换。设计层（纯文本 JSON spec 输出）不受此影响，只有需要函数调用的环节才涉及。

## 3. 任务-层级决策树

```
批量提示词任务
├─ 单条中文快速出 → generate 快路径（不用本 skill）
└─ 走工作流
   ├─ 商业交付 / 重点 IP（EQG 等）→ T0 旗舰（DeepSeek V4 / Qwen3.5-Max），ON thinking，temp 0.5-0.7
   ├─ 常规批次（6 场景）→ T0 设计脑（场景/作文） + T1 补全手（8-Block），thinking 按阶段预算表
   ├─ 大批量低价值（30+ 场景流水线）→ 设计 T0 一次，之后 T2 批量分流（V4-Flash）
   └─ 标签预处理/去重/热度筛 → T2（OFF，temp 0）
```

## 4. 降级规则

1. **T0 不可用**（超时/限流/异常）→ 自动降 T1 备份模型，thinking 降为 medium；质量下降时在交付说明里标注。
2. **T1 不可用** → T2 顶上（标签补全质量可接受，叙事不行）。
3. **任何降级都不改 spec 契约**——契约是 JSON，与模型无关。
4. **引擎层永不降级**：flow/validate 是确定性脚本，是唯一权威终检，模型层出错不能绕过。

## 5. 质量闸门阈值

- 换便宜模型：黄金集评分降幅 **<2%** 可接受；**>5%** 立即回退高层级。
- 7 维评分 <3 → 该批次不合格，回设计层修 spec，不交付。
- 足袜控/反差系常见 3.4-3.7 —— 这是目标区间，不是天花板。

## 6. 采样纪律（绘画域特化）

- **创作（T0）**: temp 0.5–0.7 才有反差惊喜；temp 0 只会复制套路——**创作阶段禁用 temp 0**。
- **严格抽取（T2）**: temp 0 + 固定 seed + 固定输入顺序（热度筛选/去重要可复现）。
- **Self-Consistency（3-5 采样投票）**: 仅用于高成本决策（如批次主题定夺），绝不逐场景用。
- **注**: `temperature=0` 不保证跨厂商确定性——复现实验要锁 seed + 输入顺序。

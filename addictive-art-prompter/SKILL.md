# Addictive Art Prompter — 成瘾性 AI 绘画提示词工程

## Overview

本 skill 基于神经科学（多巴胺预测误差）、认知心理学（信息缺口/认知闭合）、
进化心理学（超常刺激/面孔优先）和视觉艺术原理，
将任意创作意图转化为具有**精神成瘾性**的 AI 绘画提示词，
使作品具备"让观众停不下来、反复回看、主动关注"的吸引力。

核心方法论：优质 AI 绘画的竞争力不在于"画得美"，而在于——
**认知缺口 × 情绪极化 × 叙事留白 × 分层细节 × 熟悉中的陌生 × 系列连续性**。

---

## 强制输出格式规范

**AI 绘画提示词是程序，不是散文。** CLIP 等视觉编码器为标签数据训练——
每个逗号分隔的 token 必须是一个独立的视觉概念。
自然语言段落会被压缩成模糊的整体语义，丢失精确控制。

### 第一原则：标签 vs 句子

```
✅ 正确：每个逗号分隔单元 = 一个独立的视觉概念，可直接被 AI 解码为单一物体/属性/动作
   小马国女孩柔柔，浅鹅黄蓬松长卷发，蝴蝶毛绒发饰，怯生生抿嘴软笑，垂眼温柔

❌ 错误：逗号之间是完整句子的拆分，拼回去是一段小说
   深紫长发汗湿贴颈散在地板，右手指尖离一颗静止篮球仅几厘米，头顶上方倒翻的水瓶已空底朝天
```

**判断方法**：脑中在一个逗号单元里插入"然后"——如果读得通，必须拆分。

### 强制拆分规则

以下模式出现时，立即拆分为多个标签：

| 句子伪装模式 | 实例（❌） | 拆分（✅） |
|:--|:--|:--|
| A + 动词 + 在/到/向 B | 汗湿贴颈散在地板 | 汗湿贴颈，散发于地 |
| A 离/距 B 仅/只/还 数量 | 指尖离篮球仅几厘米 | 右手伸向静止篮球，指尖距球几厘米 |
| A 已/正/仍/还在 状态 | 水瓶已空底朝天 | 倒翻空水瓶，瓶底朝天 |
| A 透入/洒入/映在 B 如 C | 余晖映在地板如金斑 | 高窗黄昏蓝紫光，地板一处金斑光 |
| A 仅/只剩/只有 B | 体育馆仅应急灯亮 | 空荡体育馆，应急灯惨白冷光 |
| A 从 B 到 C 的 D | 从左窗洒入的黄昏光 | 左窗洒入，黄昏蓝紫光 |

**强制执行**：输出每条提示词后，逐一对每个逗号单元做"独立可画测试"——去掉前后文，这个单元能否被 AI 独立画出来？不能 → 拆分。

### 输出格式模板

```
通用基底词组：[精简风格/质量词，≤15条，逗号分隔]

提示词1：[8-Block标签串]，通用基底词组
提示词2：[8-Block标签串]，通用基底词组
```

### 8-Block 标签结构（每条提示词的内核）

每条提示词内的标签按以下顺序排列，块之间用 `，` 自然分隔：

```
[身份]        ← 系列名，角色名，人数
[面容+表情]   ← 发型，发色，眼型，眼神方向，唇形，腮红（≤3个表情标签）
[身体]        ← 体型，肤色，皮肤质感
[服装]        ← 头饰→耳饰→颈饰→外套→上装→下装→腰饰→手套→袜子→鞋子→手持物
[动作+姿态]   ← 主动作，身体朝向，重心
[场景]        ← 地点，道具，光源，氛围（≤2个场景标签）
[通用基底]    ← 风格/画质词，作为末尾标签
```

**重要：通用基底词组放在最末尾，作为[质量尾]的一部分。**

### 标签格式规则（强制执行）

1. **每个标签一个视觉概念**：一个逗号单元 = 一个发型/一件衣服/一个动作/一个道具/一个光源。不可将完整的情节描述塞进一个标签。

2. **禁止句子连接词**：不可出现"因为""但是""然后""当…时""正…着"等连接词。标签之间是并列的视觉要素，不是因果或时序关系。

3. **不写不可画的概念**：不写"她想起了什么""她害怕被拒绝""她犹豫了很久"——这些CLIP无法解析为视觉信号。只能写可见的东西：抿紧的嘴唇/攥到发白的指节/盯着地面的眼睛/没按下去的手指。

4. **成瘾钩子必须是可视的**：不写"镜子里的表情不真实"，写"镜中倒影嘴角上扬而实脸嘴角水平"。不写"袜子上有抽丝她没发现"，写"丝袜内侧极细抽丝一道爬向膝盖"。

5. **通用基底词组精简至≤15个标签**：仅含风格词、画质词、整体视觉调性词。一个系列内不变。

6. **标签总数控制**：单条提示词 25-50 个标签为最优区间。超过 60 开始稀释。

7. **通用基底词组放在每条提示词最末尾**。

### 服装块排序（不可违反）

头饰 → 耳饰 → 颈饰 → 外套 → 上装 → 下装 → 腰饰 → 手套 → 袜子 → 鞋子 → 手持物

## Step 1: 需求诊断 — 确定情绪极向与视觉方向

首先确认用户意图的核心情绪极向。成瘾性作品的情绪锚点不是"中性美"，而是**极端+矛盾**的组合：

| 情绪极向 | 核心感受 | 适配场景 | 关键词方向 |
|:---------|:---------|:---------|:-----------|
| 极致孤独/宁静 | 与自己独处的治愈 | 个人壁纸、情绪树洞 | liminal space, empty space, solitude, quiet night |
| 极致震撼/崇高 | 面对巨大存在的敬畏 | 世界观展示、场景大片 | megalophobia, divine light, universe, scale |
| 微度诡谲/不安 | 说不出哪里怪的沉浸 | 悬疑叙事、阈限空间 | eerie, uncanny valley lite, subtle unease |
| 破碎的华丽 | 美与毁灭的张力 | 视觉冲击、赛博朋克 | decay + beauty, ruin + treasure |
| 孤独的热闹 | 人群中独处的共情 | 打工人共鸣、都市感 | crowd + solitude, city + empty feeling |
| 治愈的忧伤 | 温柔地缅怀过去 | nostalgia 系列、回忆感 | bittersweet, nostalgic, gentle sadness |

**输出格式**：确定 1 个情绪主调 + 1 个矛盾副调，形成"矛盾的混合情绪"。
例：主调=孤独，副调=温暖 → "被温暖包裹的孤独"

## Step 2: 理论注入 — 加载成瘾机制

根据作品类型，从参考文件 `references/addiction_mechanisms.md` 中加载对应的成瘾机制模块：

### 2.1 认知缺口注入（Cognitive Gap Injection）

**原理**（预测误差理论）：大脑是模式识别机器。当画面"80% 可理解 + 20% 无法预测"时，
触发最佳预测误差，多巴胺释放量最大。

**注入方法**：

1. **叙事留白**：画面只呈现故事的"中间切片"，前因后果完全留白
   - 技法：半开的门、回眸的眼神、掉落的物品、未说完的对话、地上未干的水渍
   - Prompt 关键词：`candid moment, interrupted scene, mid-action, narrative pause, untold story`

2. **信息不对等**：角色知道/看到观众不知道的东西
   - 技法：角色看向画外（在看什么？）、伸手但没碰到、张嘴但没说话
   - Prompt 关键词：`looking off-screen, reaching towards something unseen, knowing glance`

3. **蔡格尼克效应钩子**：未完成的事记住得更牢
   - 技法：只画故事的前半秒，不画结局
   - Prompt 技法：`just before..., about to..., the moment before the door opens`

### 2.2 认知失调注入（Cognitive Dissonance Injection）

**原理**（超常刺激 + 认知失调）：两个不该共存的事物和平共处，大脑不得不停下来解构。

**注入方法**：

1. **熟悉 + 陌生配方**：
   - 技法：在熟悉场景中塞入一个"不对劲"的元素
   - 教室窗外不是操场 → 是深海；婚礼头纱下 → 是星空；医院走廊尽头 → 脚尖朝你的医生
   - 公式：`[日常场景]` + `[一个违反物理/常识的元素]` + `[角色对此习以为常]`

2. **概念矛盾重置**（Concept Paradox）：
   - 技法：热带鱼在废弃地铁 / 书房中央长着樱花树 / 雪山峰顶的自动贩卖机
   - 关键：两个元素的融合必须"视觉上可信"——光照、色调、比例必须统一
   - Prompt 提示：先分别写好两个元素，再用统一的光影/色调词包覆

3. **材质/比例置换**：
   - 技法：玻璃质感的人体、液体金属的花朵、微缩在茶杯里的星系
   - Prompt 关键词：`made of liquid metal, translucent skin, microscopic universe inside a teacup`

### 2.3 情绪极化注入（Emotional Polarization）

**原理**：单一情绪（纯美/纯恐怖）消退极快；混合情绪在大脑中持续残留数倍时间。

**注入方法**：

1. **情绪矛盾公式**：`[暖色调/柔和光]` + `[冷情绪/孤独内容]`（或反过来）
   - 例：温暖的夕阳 + 独自坐在长椅上的人 = 被温暖的孤独
   - 例：冷蓝色调 + 拥抱的两人 = 被冷峻包裹的温情

2. **以身载情**：不描述情绪词，用具体场景承载
   - 不要 "sad" → 用 "深夜便利店单人座位" / "雨天车窗上的手印"
   - 不要 "happy" → 用 "刚晒好的被子散发着阳光味" / "久别重逢时颤抖的手"
   - 不要 "lonely" → 用 "热闹聚会里背对人群的人" / "凌晨写字楼里唯一亮着灯的窗户"

3. **情绪残留技法**：
   - 画"事件发生之后"而非"事件本身"
   - 例：不画拥抱 → 画拥抱后的空椅子 / 不画争吵 → 画地上摔碎又没捡起来的杯子

### 2.4 分层信息密度注入（Multi-Layer Information Density）

**原理**：人脑的视觉奖励是分层的——远看（0.5s）、细看（3s）、放大看（10s+），
每一层都提供新的奖励。

**三层结构设计**：

| 层级 | 停留时间 | 内容 | Prompt 实现 |
|:-----|:---------|:-----|:-----------|
| L1 表层 | 0.5s | 色彩、光影、主体轮廓 | 极致的光影设定、风格化色彩、符合大众审美的主体 |
| L2 中层 | 3-10s | 道具、纹理、表情、服装细节 | 物品暗示（旧照片、没写完的信、半杯水） |
| L3 深层 | 10s+ | 隐喻符号、隐藏彩蛋、视角反差 | 远景小人/符号、镜面反射内容、隐藏的第二张脸 |

**Prompt 实现关键词**：
- L1: `cinematic lighting, striking color palette, strong silhouette`
- L2: `intricate details, background storytelling, scattered personal objects, textured surfaces`
- L3: `hidden symbols in reflections, easter eggs in the background, microscopic details in shadows`

### 2.5 视觉韵律注入（Visual Rhythm）

**原理**：视线在画面中不断游走形成闭合循环，无法"一眼看完"。

**注入方法**：
1. **S 型/螺旋型构图**：视线从角落进入 → 沿曲线 → 停在主角 → 回到角落
2. **引导线**：用透视线条、人物视线方向、光影边缘引导眼球
3. **多焦点设计**：不止一个视觉焦点——主角是焦点 A，远处光源是焦点 B，地面物品是焦点 C
4. **画内画外**：角色视线指向画外，让观众追问"TA 在看什么"

**Prompt 关键词**：`dynamic composition, leading lines, S-curve composition, multiple focal points, figure looking off-frame`

### 2.6 视觉签名注入（Visual Signature）

**原理**：观众通过专属视觉符号形成条件反射——看到符号就期待你的内容。

**注入方法**：
1. **选择一个不可替代的视觉元素**：特定色彩组合、反复出现的意象（蝴蝶/月亮/钟表/窗户）、一种固定的构图习惯
2. **每张都有但不喧宾夺主**：在背景/阴影/道具中藏入
3. **符号必须是"发现"而非"看到"的**：让人有"我找到了"的奖励感
4. **颜色记忆锚**：为整个系列设定一个专有色调（如"黄昏侧光 + 青橙对比"）

## Step 3: 系列架构 — 设计叙事弧与周期输出

单张爆款留不住人，必须做**主题化周期输出**。加载 `references/series_design.md` 获取详细方案。

### 3.1 三种系列类型及适用场景

| 类型 | 适用场景 | 强度 |
|:-----|:---------|:-----|
| **概念拟人/重塑** | 利用已有流行符号（十二星座/二十四节气/情绪主题） | ★★★ |
| **世界观碎片** | 构建统一世界，每张揭示一个地点/角色/事件 | ★★★★★ |
| **视觉连续剧** | 固定主角在不同场景的探索/遭遇 | ★★★★ |

### 3.2 系列化核心原则

1. **开放式叙事线**：每张给一点新信息，但永远不给全。发图顺序不按时间线排列。
2. **渐进揭示**：每张比前一张多透露一点——门缝→门开15度→门开45度→门全开但人走了
3. **可讨论性设计**：每期留一个"评论区填空题"——"TA 在看什么？"、"下一扇门后是什么？"
4. **变额强化**：固定角色/风格（可预测）+ 每次不同的场景/细节（不可预测）= 持续追更

### 3.3 交互闭环设计

- **开放式叙事共创**：配文留白 → 观众评论区写故事 → 高赞故事做成下一张
- **视觉谜题互动**：画面中藏数字/符号/物品 → 猜对获专属奖励
- **记忆投稿**：让观众用一句话描述难忘瞬间 → 选投稿做成 AI 绘画

## Step 4: Prompt 审计 — 10 维度成瘾性评分

对生成的 prompt 进行 10 维度评分（每项 0-10 分）：

| # | 维度 | 检查问题 | 权重 |
|:--|:-----|:---------|:-----|
| 1 | 认知缺口 | 画面上有什么是"没说破"的？观众能脑补多少？ | ⭐⭐⭐⭐⭐ |
| 2 | 情绪极化 | 是单一情绪还是矛盾混合情绪？ | ⭐⭐⭐⭐⭐ |
| 3 | 分层信息 | 是否有 3 层信息密度（0.5s / 3s / 10s+）？ | ⭐⭐⭐⭐⭐ |
| 4 | 叙事留白 | 这张图是"完整故事"还是"故事切片"？ | ⭐⭐⭐⭐ |
| 5 | 身份投射 | 观众能否在画面中"看到自己"？ | ⭐⭐⭐⭐ |
| 6 | 认知失调 | 有没有"熟悉+陌生"的矛盾元素？ | ⭐⭐⭐⭐ |
| 7 | 视觉韵律 | 视线是否能在画面中形成闭合循环？ | ⭐⭐⭐ |
| 8 | 色彩节奏 | 是否 90% 低饱和 + 10% 高饱和的节奏？ | ⭐⭐⭐ |
| 9 | 风格辨识 | 是否有视觉签名/专属符号？ | ⭐⭐⭐ |
| 10 | 系列牵引 | 看完这张是否想看上一张/下一张？ | ⭐⭐⭐ |

**总分 ≥ 70/100 → 成瘾潜力高**
**总分 50-69 → 需优化特定维度**
**总分 < 50 → 缺乏成瘾性，建议重新设计**

## 反成瘾误区 & 标签合规检查（必查）

输出前逐项确认：

### 成瘾性检查
- [ ] 画面是否"太满"？→ 必须留白（构图留白 + 情绪留白 + 叙事留白）
- [ ] 是否过度写实？→ 适当虚化/风格化，留想象空间
- [ ] 是否在单纯炫技？→ 情绪 > 技巧，内容 > 形式
- [ ] 是否只有"漂亮"没有层次？→ 必须有中层和深层信息
- [ ] 是否每一张都完整？→ 系列中每张都是未完成的故事切片
- [ ] 是否过度依赖美女/性感？→ 美女 + 信息缺口 > 美女本身

### 标签合规检查（强制）
- [ ] 每个逗号单元能否独立描述一个视觉元素？（不能 → 拆开，是句子伪装）
- [ ] 有无"但是""因为""然后""当…时""正…着"等连接词？（有 → 删除并拆分为独立标签）
- [ ] 有无不可画的概念？（"想起""犹豫""害怕""回忆"→ 替换为可见动作/物品）
- [ ] 成瘾钩子是可见的视觉细节还是情节描述？（后者 → 改成视觉细节）
- [ ] 总标签数是否在 25-50 之间？（超过 → 删减；不足 → 补充）
- [ ] 服装块排序是否正确？（头→耳→颈→外套→上装→下装→腰→手套→袜→鞋→手持物）
- [ ] 通用基底词组是否精简至 ≤ 15 个？

# wb-cli 输出契约模板

> 来源：`workbuddy-pseudo-cli-design.md` §6。所有命令响应必须符合本模板，保证可扫描、可机器解析。

## 统一模板

```markdown
## wb /sdd spec 知识库导入        ← ① 命令回显
mode: sdd · cwd: D:\... · branch: main · 耗时 00:12   ← ② 状态行

**结论**：规范已产出，含 3 个实现决策 + 5 个测试接缝   ← ③ 结论先行

| # | 决策 | 状态 |
|---|------|------|
| 1 | Docling 作为解析后端 | ✓ |

**下一步**：`/sdd tickets` 拆解为垂直切片   ← ⑤ 下一步建议
```

## 五要素

| # | 要素 | 规则 |
|---|------|------|
| ① | 命令回显 | `## wb /<cmd> <args>`，让用户看到命令被正确解析 |
| ② | 状态行 | `mode · cwd · branch · 耗时`，一行内 |
| ③ | 结论 | 第一句即结果，禁止先铺垫 |
| ④ | 表格 | 清单/状态/对比一律 Markdown 表格 |
| ⑤ | 下一步 | 附可重放的下一条命令，形成命令链 |

## 状态符号

| 符号 | 含义 |
|------|------|
| `✓` | 成功 |
| `⚠` | 警告（部分完成/降级） |
| `✗` | 失败 |
| `…` | 进行中 |
| `↳` | 子项缩进 |

## 错误码

| 码 | 含义 | 响应行为 |
|----|------|----------|
| `E0` | 成功 | 正常输出 |
| `E1` | 未知命令 | 建议最近命令 + 降级自然语言 |
| `E2` | 参数缺失/非法 | 输出 usage |
| `E3` | 状态文件损坏 | 重建默认状态，继续 |
| `E4` | 工具不可用 | 按降级链替代，标注"用了什么替代" |
| `E9` | 用户中断 | 保存状态，输出当前进度摘要 |

## 输出纪律

1. **结论先行**：第一行即结果，细节在表格
2. **表格优先**：对比/清单/状态一律 Markdown 表格
3. **无废话**：不做客套、不重复命令文本
4. **可重放**：任何输出都附 `下一步命令`，形成命令链

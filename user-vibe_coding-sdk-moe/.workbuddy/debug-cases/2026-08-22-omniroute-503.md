## [2026-08-22] OmniRoute 免费池 503：golden-run 崩溃暴露健壮性缺陷

- 环境: OmniRoute（`$OMNIROUTE_URL` 本地网关，免费 combo 池）+ golden-run.py
- 确定性阶段命中: 签名匹配（HTTP 503 "Maximum combo retry limit reached"）
- 轨迹: golden-run 在线跑金标集 → urllib HTTPError 未捕获 → 脚本崩溃（traceback）→ 手动探测：auto/best-fast 503、auto/best-chat/coding/free 空响应、oc/deepseek-v4-flash-free 403 → 判定免费池上游瞬时不稳定
- 修复: llm_complete 加 HTTPError/URLError/超时捕获，错误写回 row（ok=false, detail="LLM call failed: ..."），不再崩溃；离线判分不受影响
- 验证: SUCCESS——离线 3/3 通过；在线跑不崩（各样本报 LLM call failed 而非 traceback）
- 教训: 免费渠道池瞬时 503 属常态；调用方必须把 LLM 调用当作可失败的外部依赖，任何 runnable 脚本都应捕获 HTTP 错误

## [2026-08-22] token-meter 对 Git Bash /tmp 路径报 "no records"

- 环境: WorkBuddy 沙箱 Git Bash + Windows Python（managed 3.13.12）
- 确定性阶段命中: 差分（同样文件用 Windows 风格临时路径 `<TEMP>` 可读）
- 轨迹: token-meter.py --log /tmp/xxx/calls.jsonl → `{"error": "no records"}` → 检查发现 Git Bash 的 /tmp 映射（Windows 临时目录）在 Windows Python 侧未解析，Path.exists() 为 False
- 修复: 测试/调用改用 Windows 风格路径（`<TEMP>/...`）；ref-19 §6-4 新增边界说明
- 验证: SUCCESS——换 `<TEMP>/calls-test.jsonl` 后 3 记录指标/成本/flags 全出，exit 0
- 教训: Git Bash 路径转换只作用于命令层，不作用于 Python 内部 open()；凡脚本报"文件不存在/无记录"先确认路径风格
